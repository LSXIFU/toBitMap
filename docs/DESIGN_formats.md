# v1.3 设计：位图格式后端 + 反向导入 + 回归预言机

> 状态：待确认（确认后才动代码）
> 前置：v1.2 已定型的单色输出（行优先 MSB）必须逐字节保持不变

## 0. 不变量（改任何东西都不能破）

1. **权威缓冲只有一个**：逻辑 1bpp 位图 `B[y][x] ∈ {0,1}`，`1` = 置位（亮）。
   它是所有格式、所有方向的唯一真相；二值化/抖动只写它，任何 codec 只读它。
2. **格式只影响编码层**：加入任何输出格式都不许重做二值化、降采样、阈值、抖动。
3. **二值化 CPU 为权威**：WebGL 路径的产出必须与 CPU 逐字节相等（已有约束）。
4. **默认行为向后兼容**：未选格式时输出与 v1.2 完全一致（`ROW_MSB`）。
5. **padding 位恒为 0**，且不参与像素等价断言（无效位，不是数据）。

## 1. 参数化 codec（本设计的核心）

三种布局是同一件事的不同取值，用 `(axis, bitOrder)` 两个参数描述，**一个实现**：

| 布局 | axis | 每字节含 | 外层遍历 | 索引公式 | bitOrder | 目标设备 |
|---|---|---|---|---|---|---|
| `ROW_MSB`（现状） | row | 8 水平像素 | y | `y*ceil(W/8) + (x>>3)` | bit = `7-(x&7)` | Adafruit_GFX `drawBitmap`、U8g2 `drawXBMP`、1bpp 横排 e-paper |
| `ROW_LSB` | row | 8 水平像素 | y | 同上 | bit = `x&7` | ST7920 类、部分老控制器 |
| `PAGE_LSB` | page | 8 垂直像素 | 页 | `(y>>3)*W + x` | bit = `y&7` | **SSD1306 / SH1106 全屏缓冲**（GDDRAM 页结构，LSB = 页内顶行） |
| `COL_LSB` | col | 8 垂直像素 | x | `x*ceil(H/8) + (y>>3)` | bit = `y&7` | 列优先竖排缓冲、部分 LED 点阵与旧字库（以驱动为准） |

**关键认识**：`PAGE_LSB` 与 `COL_LSB` 的字节内部构造完全相同（8 垂直像素、LSB 在顶），只差外层遍历顺序。所以它们是同一个 permutor 的两组参数，不是两份代码。

实现形态（唯一实现原则，替换现有 `packBitmapBytes()` 内部）：

```
permute(src, dst, W, H, {axis, bitOrder})   // 双向：正向=encode，反向=decode
encode(B, fmt) -> Uint8Array
decode(Uint8Array, fmt, W, H) -> B
```

`encode` 与 `decode` 共用同一张索引表（一次生成、复用），decode 只是把映射取逆，不写第二段循环逻辑。

### 尺寸语义（必须写死）

- 每个布局的缓冲区长度：`row` → `H*ceil(W/8)`；`page` → `ceil(H/8)*W`；`col` → `W*ceil(H/8)`。
- 宽/高不是 8 的倍数：末字节高位（或末页下方）填 0，且**判断有效位时按 `W`、`H` 掩掉**，不参与比较。
- `H` 非 8 倍数时，`PAGE_LSB` 的末页仍按整字节导出（SSD1306 刷屏需要整字节），不做裁剪。
- `W/H` 仍受 `readBitmapSize()` 的 1~1024 夹紧。

## 2. 反向导入

### 输入来源
1. **`.raw`**：走现有 12 字节小端头（frames/fps/width/height），格式由用户选（头里没有格式字段，本次**不改头**，保持兼容；格式靠 UI 选择，多帧时全部按该格式解）。
2. **裸字节流 / C 数组片段**：从结果区或文件粘贴 `0xNN,` 序列（正则提取），需用户填 `W/H` + 格式。
3. 判定路径：有合法头 → 自动取 W/H；否则要求显式填写，缺失时明确报错而不是猜。

### 产出
- 预览（多帧时可翻帧，复用现有预览 canvas 逻辑）
- 可二次导出（导出走正常发射器，于是“导→读→再导”闭环）
- 显示字节数与“有效位/填充位”统计，让用户一眼看出格式选错（选错时预览是雪花/错位条纹，不是空白）

### 一条必须成立的往返
`decode(encode(B,f), f, W, H) == B` 逐位相等，对 f ∈ {ROW_MSB, ROW_LSB, PAGE_LSB, COL_LSB} 以及非 8 倍数尺寸（如 37×23、1×1、W=1、H=9）都成立。

## 3. 回归预言机（第 4 项）

不用外部图片，用**合成样本生成器**（可复现、无素材依赖）：

| 样本 | 用途 |
|---|---|
| 左黑右白（竖分界） | 抓水平和列优先的方向反了 |
| 上黑下白（横分界） | 抓页/列方向的上下翻转 |
| 单像素（四角 + 中心） | 抓 bitOrder 反了（MSB/LSB 差一位） |
| 棋盘（1px、3px 周期） | 抓 stride 错位 |
| 双峰灰阶（100/255）+ 抖动 | 抓抖动后按位比较（已有断言 #9 复用） |
| 非 8 倍数：37×23、9×9、1×1、64×9 | 抓 padding 与末页语义 |

断言矩阵：
1. 单格式自洽：`decode(encode(B,f),f) == B`
2. 跨格式等价：`decode(encode(B,f1),f1) == decode(encode(B,f2),f2)`（不直接比字节——不同布局字节本来就不同）
3. 与 v1.2 对齐：`encode(B, ROW_MSB)` 与旧实现输出**逐字节相等**（用 git worktree 跑旧版做对照组）
4. 全部样本 × 4 格式 × 上述 3 条 = 主干；任一失败即拦。

新增第 13/14 条回归（追加到项目笔记）：
13. `PAGE_LSB` 导出 128×64 必须正好 1024 字节，且 `buffer[page*128+x]` 的 LSB 对应 `y = page*8`。
14. 选错格式导入不崩：给出可读错误或明显错位预览，绝不静默显示空白。
